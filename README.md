# แต่งรูปง่าย

โปรแกรมแต่งรูปบนเว็บ ใช้ได้ทั้งคอมพิวเตอร์และมือถือ ทุกอย่างประมวลผลในเครื่องของผู้ใช้ รูปไม่ถูกอัปโหลดไปที่ไหน

เปิดใช้งาน: https://int-system.github.io/Design_Picture/

## ฟีเจอร์

- ตัดลายเซ็น (พื้นหลังโปร่งใส)
- แต่งสีและฟิลเตอร์ 16 แบบ
- สแกนเอกสาร ดัดให้ตรง รวมเป็น PDF
- ลบสิ่งที่ไม่ต้องการ / ลบลายน้ำ (คัดลอกลวดลายแบบ Content-Aware Fill)
- ปิดหน้าและข้อมูลส่วนตัว (หาใบหน้าอัตโนมัติ)
- ครอป หมุน ปรับขนาด
- เพิ่มคนหรือสิ่งของ (ตัดพื้นหลังด้วย AI)
- แก้หลายรูปพร้อมกัน แล้วดาวน์โหลดเป็น ZIP

## ติดตั้งเป็นแอป

- **คอมพิวเตอร์ (Chrome / Edge):** กดปุ่ม "ติดตั้งแอป" มุมขวาบน หรือไอคอนติดตั้งในแถบที่อยู่
- **Android:** กดปุ่ม "ติดตั้งแอป" หรือเมนู ⋮ → "ติดตั้งแอป"
- **iPhone / iPad:** เปิดใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"

หลังติดตั้ง ใช้งานได้แม้ไม่มีอินเทอร์เน็ต (ฟีเจอร์ AI ต้องเคยใช้ครั้งหนึ่งตอนออนไลน์ เพื่อเก็บไฟล์โมเดลไว้ในเครื่อง)

## โครงสร้างไฟล์

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
|---|---|
| `index.html` | ตัวโปรแกรมทั้งหมด |
| `sw.js` | Service worker เก็บไฟล์ไว้ในเครื่องเพื่อใช้ออฟไลน์ |
| `manifest.webmanifest`, `icons/` | ข้อมูลสำหรับติดตั้งเป็นแอป |
| `vendor/opencv/` | OpenCV.js 4.10 (หามุมกระดาษ, ลบแบบเกลี่ยสี) |
| `vendor/mediapipe/` | MediaPipe Tasks Vision 0.10.14 (ตัวรัน AI) |
| `vendor/models/` | โมเดลตัดพื้นหลังคน, สัตว์/สิ่งของ และหาใบหน้า |
| `vendor/fonts/`, `vendor/tabler/` | ฟอนต์ IBM Plex Sans Thai, Prompt และไอคอน Tabler |

ไลบรารีทั้งหมดเก็บไว้ใน repo เอง ไม่ต้องพึ่งเว็บภายนอก จึงใช้ได้แม้เครือข่ายบริษัทบล็อก CDN

## การอัปเดต

- แก้ `index.html` แล้วอัปโหลดขึ้น repo ได้เลย ผู้ใช้จะได้เวอร์ชันใหม่เมื่อเปิดแอปครั้งถัดไป
- ถ้าแก้หรือเพิ่มไฟล์ใน `vendor/` ให้เปลี่ยน `LIBS` ใน `sw.js` เป็นเวอร์ชันใหม่ (เช่น `libs-v2`) เพื่อให้เครื่องผู้ใช้โหลดไฟล์ใหม่
- ถ้าแก้ไฟล์ใน `SHELL_FILES` (ฟอนต์ ไอคอน) ให้เปลี่ยน `SHELL` เป็นเวอร์ชันใหม่
